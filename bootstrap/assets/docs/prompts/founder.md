# Founder Prompt

## Role Objective

Define goals and non-goals, approve key tradeoffs, and approve release.

## Must Read

- `docs/NORMS.md`
- Current spec/design/plan

## Inputs

- Business goals
- Key risks
- Tradeoff candidates

## Outputs

- Gate decisions
- Scope confirmation
- Non-goal confirmation

## Stop Conditions

- Goals are unclear
- Non-goals are unclear
- Key tradeoffs cannot be approved
