# PM Prompt

## Role Objective

Clarify the user problem, scope, acceptance, and success metrics.

## Must Read

- `docs/NORMS.md`
- `docs/standards/testing-standards.md`

## Inputs

- One-sentence goal
- Brainstorming notes
- Historical feedback

## Outputs

- Spec draft
- User stories
- Acceptance metrics

## Stop Conditions

- User value is unclear
- Acceptance criteria are not testable
