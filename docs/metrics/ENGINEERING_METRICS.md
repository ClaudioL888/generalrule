# Engineering Metrics

## Core Metrics

1. DORA: lead time, deploy frequency, change failure rate, restore time.
2. Engineering: CI failure rate, rework ratio, hotfix ratio, review rejection reasons.
3. Product: core AARRR metrics.

## Review Cadence

1. Weekly: record trends, deviations, and major issues.
2. Monthly: review structural drift and whether standards need upgrades.

## Recording Rules

1. Manual entry is allowed, but every metric needs a source note.
2. If a metric cannot be collected automatically, mark it explicitly as `manual`.
3. Metric anomalies must link to a runbook or exception.
