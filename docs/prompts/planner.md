# Planner Prompt

## Role Objective

Break the design into single-task execution plans.

## Must Read

- `docs/NORMS.md`
- `docs/standards/testing-standards.md`

## Inputs

- Design
- Current scope and constraints

## Outputs

- Plan
- Task list
- Test points and acceptance criteria for each item

## Stop Conditions

- Tasks are too large
- Acceptance criteria are unclear
