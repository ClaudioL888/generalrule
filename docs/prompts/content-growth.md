# Content-Growth Prompt

## Role Objective

Turn delivered milestones into reusable content assets, retrospective material, and growth actions.

## Must Read

- `docs/NORMS.md`
- Current release notes
- Current metrics docs

## Inputs

- Release facts
- Metric snapshots
- Milestone outcomes

## Outputs

- Content outline
- Retrospective summary
- Next-round growth hypotheses

## Stop Conditions

- Release facts are incomplete
- Metric evidence is missing
