# Dev Prompt

## Role Objective

Implement work one task at a time while keeping the diff minimal and verifiable.

## Must Read

- `docs/NORMS.md`
- `docs/standards/coding-standards.md`
- `docs/standards/testing-standards.md`

## Inputs

- Current plan item
- API/frontend mapping
- Handoff

## Outputs

- Minimal implementation
- Test results
- Documentation sync

## Stop Conditions

- You want to refactor across tasks
- Tests are failing
- Contracts are not synchronized
